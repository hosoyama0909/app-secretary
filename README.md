# app-secretary

家庭の庶務（家計・家電・住宅・車・教育費・消耗品ほか）を、**台帳＋期日ダッシュボード**として一元管理するアプリ。バニラ HTML/CSS/JS の単一ファイル・サーバ不要（`template-vanilla-webapp` から作成）。

## 中身

- `index.html` … アプリ本体。これ1つで動く。
- `worker/` … 音声/会話/写真からの下書き入力を支える Cloudflare Worker（Gemini中継）。任意（設定しなくてもアプリ本体は動く）。

## 3つの画面

- 🔔 **期日**: 全カテゴリ横断で、近い期日から一覧表示（今月/3ヶ月/すべてで絞り込み）
- 🗂️ **台帳**: カテゴリ → 記録一覧 → 記録の編集（項目・期日・メモ）
- ⚙️ **設定**: カテゴリの追加、AI下書き用 Worker URL、JSONエクスポート/インポート、全消去

## データモデル（拡張しやすい構成）

カテゴリ（ドメイン）はフィールド定義を**データとして**持つ。新しい庶務ドメインを増やすときは、
設定画面から「カテゴリを追加」するだけでよく、コード変更は不要。

```
Category: { id, name, icon, fields: [{key, label, type, unit?, options?}], dateHints: [] }
Item:     { id, categoryId, values: {...}, dates: [{label, mode: once|yearly|interval, date, intervalMonths, leadDays}], memo }
```

初期プリセットは17ドメイン: 家計・資産／家電／住宅／車／教育費／消耗品／保険／契約・サブスク／
税金／証明書・書類／健康・医療／学校・保育園／季節タスク／防災備蓄／冠婚葬祭・贈答／
ポイント・クーポン／実家・親族。

## AI下書き入力（音声 / 会話テキスト / 写真OCR）

入力の手間を減らすため、記録の編集画面に「✨ 楽な入力」パネルがある。

- 🎤 **音声**: ブラウザ標準 Web Speech API でその場に文字起こし（バックエンド不要）
- 📝 **会話テキスト**: ラフな文章（例：「冷蔵庫、パナソニックの、去年の3月にヤマダで18万、保証5年」）を
  Worker 経由で Gemini に渡し、カテゴリのフィールド定義に沿った JSON を受け取ってフォームに反映
- 📷 **写真**: 保証書などを撮影し、同じ仕組みで下書きを作成（画像は保存せず、抽出後に破棄）

いずれも **AIは下書きを作るだけ**で、保存前に必ず内容を確認する（human-in-the-loop）。
Worker を使うには `worker/README.md` の手順でデプロイし、⚙️設定に URL を登録する。

## 方針（このプロジェクト共通）

- **実データは端末内 `localStorage` のみ**。コード・リポジトリには一切置かない。
- AI下書きのためにテキスト/画像を外部AI（Gemini）へ送信することがある（設定でWorker URLを登録した場合のみ）。
  🔴機微情報（口座番号フル・暗証番号・カード番号・マイナンバー・パスワード）は、抽出させず・アプリにも入力しない。
- デザインはシンプル志向。家族（小さい子ども）も使うため、タップ領域は大きめ・導線は分かりやすく。
- 家族間の共有は当面 JSON エクスポート/インポートで行う（更新頻度が低いため）。将来的に必要になれば
  Cloudflare Worker + KV/D1 での同期を検討する。
