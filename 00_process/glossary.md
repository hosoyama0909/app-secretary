# 用語集（Glossary）

| 用語 | 意味 |
|------|------|
| A-SPICE | Automotive SPICE。自動車ソフト向けのプロセス参照・アセスメントモデル。 |
| 作業成果物 (Work Product) | 各プロセスが生成する文書・コード・テスト等。 |
| トレーサビリティ | 要求〜テスト間の対応関係。上流・下流の双方向でたどれること。 |
| 一貫性 (Consistency) | トレースで結ばれた成果物同士の内容が矛盾しないこと。 |
| テーラリング | 標準プロセスをプロジェクト事情に合わせて調整すること。 |
| 能力レベル | プロセスの成熟度（0〜5）。 |
| CR (Change Request) | 変更依頼。 |
| カテゴリ（ドメイン） | 秘書アプリの管理分野（家電・車・保険…）。フィールド定義を持つデータ。 |
| アイテム（レコード） | あるカテゴリに属する1件の記録（値＋期日＋メモ）。 |
| 期日エンジン | 単発/毎年/nヶ月ごと から次回期日を計算する仕組み。 |
| 日記（Journal） | 日付ごとの出来事の記録（本文＋気分＋タグ＋関連カテゴリ）。 |
| 俯瞰タイムライン | 日記と期日を today を中心に1つの時系列に混ぜて見せるビュー（上=これから／下=これまで）。 |

## 要求・設計IDの採番規則

| 接頭辞 | 種別 | 例 | 対応プロセス |
|--------|------|----|--------------|
| `STK-` | ステークホルダ要求 | STK-02 | SYS.1 |
| `SYR-` | システム要求 | SYR-10 | SYS.2 |
| `SWR-` | ソフトウェア要求 | SWR-DUE-02 | SWE.1 |
| `SWA-` | ソフトウェアアーキ要素 | SWA-LEDGER | SWE.2 |
| `SWD-` | 詳細設計要素 | SWD-computeNextDate | SWE.3 |
| `UTC-` | 単体テストケース | UTC-DUE-01 | SWE.4 |
| `QTC-` | 適格性テストケース | QTC-LEDGER-01 | SWE.6 |
| `RSK-` | リスク | RSK-03 | MAN.5 |

機能ごとに中間キーを入れてよい（例：`SWR-DUE-*` = 期日ダッシュボード, `SWR-CAT-*` = カテゴリ管理,
`SWR-AI-*` = AI下書き入力, `SWR-DATA-*` = データ入出力, `SWR-JOURNAL-*` = 日記, `SWR-TL-*` = 俯瞰タイムライン）。
