# SYS.1 ステークホルダ要求

出典：壁打ち・構想ノート（`docs-private` の `30_Projects/アプリ開発/秘書アプリ構想.md`）から抽出。
ステークホルダ＝オーナー（開発者本人）＋利用者（家族：妻・子ども）。

| ID | ステークホルダ要求 | 由来 | 優先度 |
|----|--------------------|------|--------|
| STK-01 | 家庭の庶務（家電・車・住宅・契約…）の情報を分野ごとに記録・確認したい | 構想「台帳」 | 高 |
| STK-02 | 保証期限・車検・更新月・納税などの期日を、忘れずに横断で把握したい | 構想「期日」 | 高 |
| STK-03 | 家計・資産・教育費など、お金まわりの状況を把握したい | 挙げた項目 | 高 |
| STK-04 | 「どこで買うと安い」「買い替え目安」などの家庭内ナレッジを添えたい | 構想「知恵」 | 中 |
| STK-05 | 管理したい分野を**後から自由に増やせる**構成にしたい | 「後からでも追加できる構成」 | 高 |
| STK-06 | 入力が面倒なので、保証書の写真・会話・音声からラクに登録したい | 追加要望 | 高 |
| STK-07 | 家族にも展開したい（まずは受け渡し、将来は共有） | 「家族にも展開」 | 中 |
| STK-08 | ログイン不要・無料で、スマホですぐ使えること | 利用者体験 | 高 |
| STK-09 | 🔴機微情報（口座番号フル・暗証番号・カード番号・マイナンバー・パスワード）を扱わず、安全であること | docs-private ガードレール | 高 |

## ロードマップとの対応（段階的実現）

- Rev 2（実装済み）＝ STK-06（AI下書き入力）
- Rev 3（予定）＝ STK-07（家族間同期。当面は JSON 受け渡しで代替）
