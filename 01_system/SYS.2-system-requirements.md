# SYS.2 システム要求分析

STK 要求を、システム（アプリ）が満たすべき要求に分解する。各 SYR は検証可能な形で書く。

## 機能要求

| ID | システム要求 | 由来(STK) | 検証 |
|----|--------------|-----------|------|
| SYR-01 | 管理分野を「カテゴリ」として持ち、各カテゴリはフィールド定義（型つき）を持つ | STK-01,05 | QTC-LEDGER-01 |
| SYR-02 | カテゴリに属する記録（アイテム）を作成・編集・削除できる | STK-01 | QTC-LEDGER-02 |
| SYR-03 | 初期状態で家庭の主要17分野をプリセットとして同梱する | STK-01,03 | QTC-LEDGER-01 |
| SYR-04 | 利用者がカテゴリを追加でき、コード変更なしに新分野を管理できる | STK-05 | QTC-CAT-01 |
| SYR-05 | 各記録に複数の期日（単発/毎年/nヶ月ごと）を設定できる | STK-02 | QTC-DUE-02 |
| SYR-06 | 全カテゴリ横断で、近い期日から並べたダッシュボードを表示できる | STK-02 | QTC-DUE-01 |
| SYR-07 | 期日を「今月／3ヶ月以内／すべて」で絞り込み、まもなく/期限切れを区別できる | STK-02 | QTC-DUE-03 |
| SYR-08 | 各記録に自由メモ（買い替え目安・安い購入先等の知恵）を残せる | STK-04 | 手動 |
| SYR-09 | データを JSON で書き出し／取り込みでき、家族と受け渡しできる | STK-07 | QTC-DATA-01 |
| SYR-10 | 全データを消去できる（初期化） | STK-01 | 手動 |
| **SYR-24** | **会話文・音声・写真から記録の下書き（フィールド値・期日）を自動生成できる** | STK-06 | QTC-AI-01 |
| **SYR-25** | **日付ごとの記録（日記エントリ）を作成・編集・削除でき、気分・タグ・関連カテゴリを付与できる** | STK-10 | QTC-JOURNAL-01,02 |
| **SYR-26** | **日記エントリと期日を1つの時系列（俯瞰タイムライン）に混在表示し、日々を俯瞰できる** | STK-10 | QTC-TL-01 |
| **SYR-27** | **タグ・期間で日記を絞り込み、整理できる** | STK-10 | QTC-TL-02 |

## 非機能要求（品質特性）

| ID | 非機能要求 | 由来 | 検証 |
|----|-----------|------|------|
| SYR-N1 | ログイン不要・サーバ不要で動作する（クライアント完結） | STK-08 | アーキ審査 |
| SYR-N2 | データは端末内（localStorage）に保持する。**AI下書きを使う時のみ**、入力（テキスト/画像）を中継サーバ経由で送信する（下記N7）。それ以外は外部送信しない | STK-08,09 | コード審査 |
| SYR-N3 | 単一 `index.html`（HTML/CSS/JS 一体）。外部ライブラリ非依存 | 制約 | アーキ審査 |
| SYR-N4 | スマホ縦画面・大きめタップ領域・片手で操作可能（家族利用） | STK-08 | 目視 |
| **SYR-N7** | **AI送信は Worker URL 登録時のみ・任意で行い、写真そのものは保存しない（抽出後に破棄）。🔴機微情報は抽出させない** | STK-09 | QTC-AI-02 |
| **SYR-N8** | **AI APIキーはクライアントに置かず、サーバ（Cloudflare Worker）側の秘匿情報として保持する** | STK-09 | アーキ審査 |
| **SYR-N9** | **AI中継サーバ未設定・通信失敗・オフライン時も、台帳・期日など既存機能は継続動作する（劣化）** | STK-08 | QTC-AI-03 |
| SYR-N10 | 🔴機微情報をアプリに保存させない方針を、UI上に明示する | STK-09 | QTC-GUARD-01 |

## 制約
- 単一 `index.html`（HTML/CSS/JS 一体）。外部ライブラリ非依存（現状）。
- ストレージは localStorage（実データは端末内のみ・画像は保存しない）。

トレースは `05_traceability/traceability-matrix.md` に集約。
