# SWE.1 ソフトウェア要求分析

システム要求（SYR）を、実装可能なソフトウェア要求（SWR）へ詳細化する。
機能ごとに中間キーを付ける（`SWR-CAT-*`=カテゴリ, `SWR-LEDGER-*`=台帳編集,
`SWR-DUE-*`=期日, `SWR-DATA-*`=入出力, `SWR-AI-*`=AI下書き, `SWR-GUARD-*`=機微情報）。

## カテゴリ／汎用台帳モデル — SYR-01,03,04 由来

| ID | ソフトウェア要求 | 由来(SYR) |
|----|------------------|-----------|
| SWR-CAT-01 | カテゴリは {id, name, icon, order, fields[], dateHints[]} を持ち、fields は {key,label,type(text/number/date/select),unit?,options?} の配列である | SYR-01 |
| SWR-CAT-02 | 起動時、localStorage にカテゴリが無ければプリセット定義を初期投入する | SYR-03 |
| SWR-CAT-03 | 設定画面からカテゴリを追加できる（名前・アイコン。既定で name フィールドを1つ持つ） | SYR-04 |
| SWR-CAT-04 | 追加したカテゴリは他機能（台帳・期日・入出力）から区別なく扱える（横断機能はカテゴリ非依存） | SYR-04 |
| SWR-CAT-05 | プリセットは家庭の主要17分野を同梱する（家計・資産／家電／住宅／車／教育費／消耗品／保険／契約・サブスク／税金／証明書・書類／健康・医療／学校・保育園／季節タスク／防災備蓄／冠婚葬祭・贈答／ポイント・クーポン／実家・親族） | SYR-03 |

## 台帳（記録の編集）— SYR-02,08 由来

| ID | ソフトウェア要求 | 由来(SYR) |
|----|------------------|-----------|
| SWR-LEDGER-01 | カテゴリ一覧（タイル）を件数付きで表示し、選ぶとそのカテゴリの記録一覧へ遷移する | SYR-02 |
| SWR-LEDGER-02 | 記録を新規作成・フィールド編集・削除できる。入力は都度 localStorage に保存する | SYR-02 |
| SWR-LEDGER-03 | 記録に複数の期日を追加・編集・削除でき、カテゴリ既定の dateHints をワンタップチップで足せる | SYR-05 |
| SWR-LEDGER-04 | 各記録に自由メモ（買い替え目安・安い購入先等）を残せる | SYR-08 |

## 期日ダッシュボード — SYR-05,06,07 由来

| ID | ソフトウェア要求 | 由来(SYR) |
|----|------------------|-----------|
| SWR-DUE-01 | 全カテゴリ・全記録の期日を集約し、次回期日の近い順に一覧表示する | SYR-06 |
| SWR-DUE-02 | 期日は3モードで次回日を算出する：once(単発=その日)、yearly(毎年その月日、過ぎていれば翌年)、interval(基準日からnヶ月ごとで今日以降の最初) | SYR-05 |
| SWR-DUE-03 | 「今月／3ヶ月以内／すべて」で絞り込める | SYR-07 |
| SWR-DUE-04 | 各期日を、残り日数とリード日数(既定30日)から「期限切れ／まもなく／通常」に色分けする | SYR-07 |
| SWR-DUE-05 | 期日行タップで、その記録の編集画面へ遷移する | SYR-06 |

## データ入出力 — SYR-09,10 由来

| ID | ソフトウェア要求 | 由来(SYR) |
|----|------------------|-----------|
| SWR-DATA-01 | categories/items/settings を localStorage に保存し、reload後も保持する | SYR-N2 |
| SWR-DATA-02 | データを JSON ファイルに書き出せる（ファイル名に日付付与）。取り込むと categories/items を復元する | SYR-09 |
| SWR-DATA-03 | 全データを消去し、カテゴリをプリセットへ初期化できる | SYR-10 |

## AI下書き入力（Rev 2）— SYR-24, N7〜N9 由来

| ID | ソフトウェア要求 | 由来(SYR) |
|----|------------------|-----------|
| SWR-AI-01 | 音声ボタンで Web Speech API により話した内容をテキスト欄に文字起こしする（非対応ブラウザではボタン無効） | SYR-24 |
| SWR-AI-02 | 「下書きを作成」で、カテゴリのフィールド定義＋テキストを中継Workerへ送り、返ったJSONをフォームに反映する | SYR-24 |
| SWR-AI-03 | 写真ボタンで画像を撮影/選択し、Workerへ送って同様に下書きを作成する | SYR-24 |
| SWR-AI-04 | 画像はアプリ内に保存せず、抽出要求のためだけに使い、要求後に破棄する | SYR-N7 |
| SWR-AI-05 | 🔴機微情報（口座番号フル・暗証番号・カード番号・マイナンバー・パスワード）は抽出させず、UIに注意書きを表示する | SYR-N7,N10 |
| SWR-AI-06 | 抽出結果は下書きとしてフォームに反映するのみで、保存は人の操作に委ねる（自動保存しない値の確定は人） | SYR-24 |
| SWR-AI-07 | Worker は GEMINI_API_KEY を secret 保持し、CORS付きで、テキスト(extract)と画像(extract-image)の両方を Gemini に代理呼び出しする | SYR-N8 |
| SWR-AI-08 | Worker URL は設定画面で登録・保存でき、未設定時は AIパネルに設定導線を出す。通信失敗時はエラー表示のみで台帳・期日は動作を継続する | SYR-N8,N9 |

## 受け入れ基準（抜粋）
- SWR-CAT-02：初回起動でカテゴリが17件表示されること。
- SWR-DUE-02：yearly で基準日が過去でも、次回は今日以降の同月日になること。interval は基準日からnヶ月刻みで今日以降の最初の日になること。
- SWR-AI-04：写真から下書きを作っても、localStorage に画像データが保存されていないこと。
